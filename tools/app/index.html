One-time setup

To build games for the 3DS, this PC needs the free devkitPro 3DS tools. You only do this once.

  1. Click Get the installer. Your web browser opens devkitPro's download page; download devkitProUpdater (the .exe file).
  2. Run it. When it asks which parts to install, tick 3DS Development. Keep the install folder as C:\devkitPro.
  3. When it has finished, click Check again.

Add a game

Paste a MakeCode Arcade share link (or a GitHub link). It is downloaded, built for the 3DS and put in the library.

Your games

Edit the details shown in the 3DS library, give games a picture (a PNG; square pixel art works best), or rebuild them. Separate several authors or tags with commas; each author and each tag gets a folder on the 3DS, and a game made by several people appears in each of their folders.
